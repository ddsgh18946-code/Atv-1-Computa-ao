# Atv-1-Computa-ao
Sistema de Vendas Simples em Python

## Descrição do Projeto
Este projeto simula um sistema de atendimento e vendas, desenvolvido para praticar os fundamentos da linguagem Python, como variáveis, tipos de dados e estruturas condicionais.

## Funcionalidades
- Validação de entrada de dados.
- Menu interativo utilizando `match/case`.
- Cálculo de preço com aplicação de desconto condicional.

## Tecnologias Utilizadas
- Python 3.10+
- Lógica de programação orientada a scripts.

## Como Executar
1. Clone o repositório.
2. Certifique-se de ter o Python instalado.
3. No terminal, execute: `python app.py`
